# Documentos del proveedor — Gufra Perú

PDFs que manda el proveedor: **proformas** (precio de compra) y **fichas técnicas** (datos del
equipo — capacidad, mV/V, dimensiones, material). No confundir con `cotizaciones-reales/` (la
carpeta de al lado), que es lo que LF Munay le cotiza AL CLIENTE — esta es lo que Gufra le
cotiza A LF Munay. Son direcciones opuestas del mismo negocio.

## Qué subir acá

Cualquier PDF que mande Gufra (o cualquier otro proveedor de balanzas, si aparece otro):
proforma con precio, ficha técnica de celda/caja sumadora/indicador/plataforma, catálogo de
producto. Sube el archivo tal cual, con el nombre que ya trae — no hace falta renombrarlo.

## Por qué importa subir estos específicos

`analisis-proveedor-gufra.md` ya identificó una lista de PDFs que el chat con el proveedor solo
menciona por nombre de archivo, sin que el precio quedara en el texto — por ejemplo la
plataforma Yaohua T7, el kit KELI Sensor de Tarapoto/Moyobamba (el que corresponde a las
cotizaciones 6112/7171), o la plataforma SCS-1515 completa. Si tienes esos PDFs guardados
(los que Gufra mandó por WhatsApp), súbelos acá — de ahí se saca el precio real que falta en
`catalogo.md`, en vez de dejarlo como "sin precio en texto".

## Qué pasa después de subir uno

Se lee el PDF, se extrae el precio y el dato técnico relevante, y se actualiza `catalogo.md`
(la única fuente de precios) y `analisis-proveedor-gufra.md` (el porqué y las notas técnicas)
con la fuente correcta. El PDF se queda acá como respaldo — no se copia el número a mano sin
dejar de dónde salió.
