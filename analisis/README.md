# Análisis de fuentes originales

El razonamiento detrás de `criterios-actuales.md`: qué se encontró en cada archivo original,
qué problemas tenía, y qué decisión terminó generando. Si una regla de `criterios-actuales.md`
alguna vez se pone en duda, el porqué está acá, no solo el "qué".

- **`cchh-cot-excel.md`** — análisis del Excel histórico de 23 hojas (una cotización suelta
  por hoja) que se usaba antes de este sistema.
- **`tarapoto-excel.md`** — análisis del Excel de la balanza de Tarapoto, que reveló cómo se
  arma realmente un costeo (costo → ganancia → precio) y el hábito de dejar preguntas
  pendientes antes de cerrar una cotización.

Los archivos originales (.xlsx) no están subidos aquí todavía — están guardados por Gera y
Claude los procesó en sesión. Si se quiere conservar el archivo crudo como respaldo además del
análisis, se puede subir a `fuentes-originales/` (pendiente de decidir si vale la pena, ver
nota al final de cada análisis).
